# Halftone — XOCE Store artwork

This directory contains checked-in masters and exports for the published
Halftone 1.10.3 presentation. Halftone retains its orange dots and centred clock;
shared title craft, device treatment and XOCE endorsement tie it to the family.

- `listing.json` and [publication.json](publication.json) identify the current publication.
- `*-family-banner.svg` / `.png` are editable banner masters and 720×320 exports.
- Listed native screenshots retain their original raw pixels and capture versions.
- `artwork-provenance.json`, `demo-capture-provenance.json` and `final-gallery-reuse.json` record artwork inputs, captures and verified reuse.
- `ARTWORK-LICENSES.txt` retains the applicable font/illustration credits.

The checked-in masters are authoritative for this repository. Maintained family
generation instructions and source are in
[XOCE artwork](https://github.com/xefensor/xoce/tree/main/artwork). Use the relevant
recipe and pinned input hashes, then review any regenerated file against its
provenance. A common generator does not turn a new render into an old capture.

Website marks, Store artwork and native launcher glyphs are distinct exports.
Halftone is a watchface: its website mark is not a watchapp Store icon upload.
The current native 25px launcher glyph is already integrated in the published
PBW. Frozen release archives are unchanged by documentation maintenance.

See [publication and local-kit boundaries](PUBLISHING.md). New assets need new
filenames/provenance and review; historical captures, official frames, released
PBWs and source archives retain their bytes.
